# ResumeAI

A smart resume-building website that helps users create a resume with career suggestions, skill recommendations, and an AI-style professional summary.

## Features

- **Career suggestions** based on the user's subject or area of study
- **Skill recommendations** to help users identify relevant skills for their chosen career
- **AI-style summary generation** for a professional resume profile
- **Resume preview** to review the resume before downloading
- **Downloadable resume** after creating and previewing it

## About

ResumeAI is designed to make resume creation easier by guiding users through career-related suggestions and helping them prepare a professional resume.
